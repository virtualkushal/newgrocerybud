# 🛒 GroceryBud (jQuery Version)

A lightweight and beginner-friendly grocery list / shopping web app built using **HTML, CSS, and jQuery**.

**GroceryBud** helps users easily add, edit, search, mark as bought, and remove grocery items.  
It is small, fast, and framework-free (only jQuery), making it perfect for learning DOM manipulation and LocalStorage.

---

## 🌐 Live Demo

👉https://github.com/virtualkushal/newgrocerybud.git

---

## ✨ Features

- ➕ Add grocery items with a title (optional notes supported)
- ✏️ Edit existing items
- 🗑️ Delete grocery items
- ✅ Mark items as bought / toggle completion
- 🔍 Search items instantly
- 💾 Save items automatically using **LocalStorage**
- 📱 Fully responsive (mobile-first UI)

---

## 🛠️ Tech Stack

- **HTML** — Structure / markup
- **CSS** — Styling and responsive layout
- **jQuery** — DOM manipulation & app logic
- **LocalStorage** — Persistent data storage
- **No backend / build tools required**
